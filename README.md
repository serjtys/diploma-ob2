# Платформа для публикации платного контента (OB2)

Дипломный проект: платформа для публикации платного контента с использованием Django, DRF, PostgreSQL, Docker, JWT и Stripe.

## Статус
🚧 В процессе разработки

## Стек технологий
- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Authentication: JWT
- Payments: Stripe
- Containerization: Docker + Docker-compose
- Frontend: Django Templates + Bootstrap
